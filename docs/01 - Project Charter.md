# Project Charter

## Project Information

**Project Name**
Fatih Roihan Portfolio Website

**Project Type**
Portfolio Website

**Project Status**
Planning

**Development Method**
Agile Scrum (Solo Developer)

## Project Objective

Membangun website portofolio profesional yang mampu menarik calon klien freelance dari Indonesia maupun internasional melalui pendekatan konsultatif dan studi kasus.

## Business Goal

- Mendapatkan project freelance.
- Membangun personal branding sebagai Fullstack Developer & IT Consultant.
- Menjadi media utama untuk menunjukkan pengalaman, solusi, dan hasil pekerjaan.

## Target Audience

- UMKM
- Startup
- Perusahaan
- Personal Brand
- Klien Internasional

## Core Services

- Company Profile Website
- Landing Page
- Custom Web Application
- Internal Management System
- Dashboard
- Business Process Automation

## Value Proposition

Saya tidak hanya membangun website, tetapi membantu menganalisis masalah bisnis, menemukan akar penyebabnya, dan merancang solusi digital yang tepat.

## Success Criteria

Website dianggap berhasil apabila:

- Mendapatkan inquiry dari calon klien.
- Mudah dipahami dalam waktu kurang dari 30 detik.
- Memiliki performa tinggi.
- Siap dibagikan ke calon klien.

- Blogger
